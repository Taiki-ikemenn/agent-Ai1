# エージェントAi

調べる・作る・送るまで手伝う AI エージェントの Web アプリです（Gemini を使用）。

- 公開ページ：https://taiki-ikemenn.github.io/agent-ai1/
- 設定のしかた：[セットアップ手順.txt](セットアップ手順.txt)

## できること
- チャット（ファイルのアップロード・画像/PDF/音声の読み取り・コードのコピーとダウンロード）
- プロジェクト（指示とメモリーを切り替えるプロファイル）
- コード（AI と一緒にプログラミング・プレビュー・ZIP・GitHub へ送信）
- ライブラリ（AI が作った画像・音楽・動画・ファイル）
- スケジュール（決めた時間に AI が自動で作業して通知）
- フィード（AI が作る SNS 風ニュース。好みは指示とスライダーで設定）
- カスタマイズ（アプリ接続・メモリー・カスタム指示・一般）
- アプリ接続：Gmail / GitHub / 天気 / YouTube / ブラウザ / Canva / Spotify / Google連絡先 / Googleフォーム / Adobe Express

## しくみ
- 1 枚の `index.html` で動きます（ホーム画面に追加すると PWA としてアイコン付きで開けます）
- データは Firebase（tai-account）の `agentai/{uid}` に保存され、端末をまたいで同期されます
- Gemini のキーやトークンはアカウントに保存せず、その端末の中だけに置きます
- 動くのはアプリを開いている間だけです（サーバー代なし）
